# Support

## How to Get Help

All community support is handled through [GitHub Issues](https://github.com/mrehman29/AutoMapSharp/issues). GitHub Discussions is currently disabled.

### Bug reports

Open an issue at <https://github.com/mrehman29/AutoMapSharp/issues/new> and include:

- The AutoMapSharp package version(s) in use.
- Your target framework (`net8.0`, `net9.0`, `netstandard2.0`, etc.).
- A minimal reproducible C# code sample or repository.
- Expected behavior vs. actual behavior, including full exception messages and stack traces.

### Feature requests and proposals

Open a GitHub issue with a clear problem statement, the rationale and use cases, and, where possible, a proposed API design.

### Questions and how-to

Open a GitHub issue labeled `question`. Before asking, please check the [README](README.md), the [documentation](docs/), and the [Migration Guide](MIGRATION_GUIDE.md).

### Security vulnerabilities

Do **not** open a public issue. Follow the private reporting process in [SECURITY.md](SECURITY.md).

## Supported Versions

| Version | Status |
| :--- | :--- |
| `1.0.x` | Current GA release line; actively maintained with bug fixes and security patches. |
| Older previews (`< 1.0.0`) | Unsupported. Please upgrade to 1.0.0 or later. |

## Expectations

AutoMapSharp is maintained on a best-effort basis by the project maintainers and community contributors. There is no guaranteed response time, but we review issues as quickly as we can. Contributions are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md).
